Designed and developed a Java-based Hostel Management System to streamline administrative operations such as student registration, room allocation, fee management, and employee record management. Built a responsive desktop GUI using Java Swing and implemented database connectivity using JDBC with an Apache Derby relational database.

The system features a secure admin login module and a centralized dashboard enabling administrators to perform CRUD operations for students, rooms, and employees. It allows efficient tracking of hostel occupancy, fee payments, employee records, and student status, improving data organization and administrative workflow.

This project demonstrates practical experience in Java application development, object-oriented programming (OOP), database integration, and event-driven GUI design, while building a real-world management system.
